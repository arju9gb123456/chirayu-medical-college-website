Connect the database

The admin panel saves into Supabase. Until it is connected you can still edit in draft mode: changes stay in this browser and you can preview them or download the file.

  1. Create a project at supabase.com.
  2. Open SQL Editor, paste supabase/schema.sql from the repo and run it.
  3. In Authentication → Users, add the admin user (email + password).
  4. Copy Project URL and anon public key from Project Settings → API into assets/js/config.js and push.
